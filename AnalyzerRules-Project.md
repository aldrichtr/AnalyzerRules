# Analyzer Rules

The purpose of this project is to provide additional PowerShell Script Analyzer Rules to enhance both formatting
(linting) as well as catching additional code smells.



## PowerShell Keywords

The following table lists the powershell keywords and their major grouping within the Analyzer Rules.

- Rule Categories
  - FormatKeywords
    - FormatNamedBlocks
      - begin
      - process
      - end
      - clean
      - data
    - FormatParameterBlocks
      - dynamicparam
      - param
    - FormatBranchingStatements
      - break
      - continue
      - return
    - FormatExceptionHandlers
      - trap
      - try
      - catch
      - finally
      - throw
    - FormatTypeStructures
      - function
      - filter
      - enum
      - class
    - FormatConditionals
      - if
      - else
      - elseif
      - switch
    - FormatVisibility
      - using
      - static
      - hidden
    - FormatIterationControls
      - do
      - while
      - until
      - for
      - foreach
      - in
